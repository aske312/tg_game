# Крысиные бега — Telegram Mini App

Первая версия: ведущий, до 8 игроков, комнаты, 20 вопросов, очки и SQLite. Python 3.9+, FastAPI, HTML/CSS/JS, WebSocket. Сборка фронтенда не требуется.

Для работы на VPS используйте [инструкцию развёртывания](deploy/README.md): локальная разработка → GitHub → сервер. Настройки и SQLite хранятся отдельно от обновляемого кода.

## Запуск на Windows

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. `DEV_MODE=true` разрешает вход под любым именем. Создайте комнату; второго игрока откройте в другом браузере или приватном окне. Дублирование вкладки может скопировать сессию.

## Telegram

### Быстрый запуск на своём компьютере

В `.env` достаточно заполнить `BOT_TOKEN`. Скачайте [cloudflared для Windows x64](https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-windows-amd64.exe) в `tools/cloudflared.exe`.

Запустите `start-telegram.cmd` двойным кликом или:

```powershell
.\.venv\Scripts\python.exe scripts/run_telegram.py
```

Команда проверяет бота, запускает сервер на `127.0.0.1:8001`, HTTPS-туннель и бота. `APP_URL` и `BOT_USERNAME` обновляются в `.env` автоматически. Для этого сервера вход без Telegram отключён, а БД хранится отдельно в `data/telegram.sqlite3`. Изменения Python-файлов в `app/` перезапускают тестовый сервер автоматически, сохраняя туннель. Логи находятся в `data/`. Остановка: Ctrl+C в окне запуска.

Откройте выведенную ссылку на бота и нажмите кнопку меню «Играть». Для приглашений через `startapp` дополнительно настройте Main Mini App в @BotFather на выданный HTTPS-адрес. Без этого игроки могут открыть бота и ввести код комнаты вручную.

Адрес туннеля меняется при каждом запуске — Main Mini App в BotFather нужно обновлять. Компьютер и окно запуска должны оставаться включёнными. Туннель не требует своего домена или аккаунта Cloudflare: [официальная документация Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/).

`start-local.cmd` запускает браузерный режим на порту 8000. Проверка в браузере и Telegram использует разные базы; комнаты между режимами не общие.

### Ручная настройка

1. Создайте бота в @BotFather через `/newbot`.
2. Заполните `.env`: `BOT_TOKEN`, `BOT_USERNAME` без @, `APP_URL` — публичный HTTPS-адрес. Перед публичным доступом установите `DEV_MODE=false`.
3. Разместите сервер за HTTPS-прокси с поддержкой WebSocket `/ws/`. Для временной проверки можно использовать HTTPS-туннель к порту 8000.
4. В @BotFather: `/mybots` → ваш бот → Bot Settings → Configure Mini App. Включите Main Mini App и задайте `APP_URL`. Это необходимо для приглашений `https://t.me/<bot>?startapp=<код>`.
5. Запустите сервер и отдельно `.\.venv\Scripts\python.exe -m app.bot`. Бот устанавливает кнопку меню и отвечает на `/start` в личном чате. Если у бота уже есть webhook, отключите его перед long polling.
6. Откройте бота → `/start` → «Открыть игру».

Токен не передаётся клиенту. Сервер проверяет подпись и возраст `initData`, выдаёт суточную сессию. Протокол: [Telegram Mini Apps](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app).

## Правила и ограничения

- Создатель обычной комнаты — ведущий: запускает игру, выбирает вопрос и оценивает текстовый ответ. Игрок нажимает «Я знаю ответ!» и отправляет ответ в чат внутри Mini App. Все участники видят сообщения; обычные сообщения без права ответа не засчитываются.
- Первый запрос «Я знаю ответ!», пришедший на сервер, получает право ответа. Транзакция SQLite исключает двух победителей при одновременном нажатии.
- Верный ответ: +стоимость; неверный: −стоимость. После ошибки могут отвечать остальные. Повторная попытка того же игрока запрещена.
- На первое нажатие — 30 секунд, ввод ответа — 20, после ошибки — 15. По истечении времени сервер блокирует отправку зачётного ответа; ведущий вручную закрывает попытку. Отправленный вовремя ответ можно оценить после таймера.
- После раскрытия ведущий переходит дальше. После 20 вопросов — результаты. Есть досрочное завершение.
- Новые игроки входят только до старта; действующие участники могут вернуться с действительной сессией.
- Демопакет: `app/questions.py`. Не меняйте его во время незавершённых игр: комнаты ссылаются на идентификаторы вопросов.
- SQLite автоматически создаётся в `data/game.sqlite3`; путь задаётся `DATABASE_PATH`. Комнаты, очки, вопрос и сессии сохраняются после перезапуска.
- Запускайте **один процесс Uvicorn, без `--workers`**: подключения WebSocket хранятся в памяти. Клиент переподключается и получает актуальное состояние.
- Передачи ведущего, редактора пакетов, рейтинга и удаления ушедших игроков пока нет. Комнаты автоматически не очищаются.

## Тестовая комната с искусственными игроками

На главном экране нажмите «Играть с искусственными игроками». Создаётся отдельная комната: ваша настоящая учётка — игрок, Робоведущий — ведущий, Сырник и Шустрик — искусственные соперники. Их роли явно подписаны. Вход через Telegram остаётся обязательным на публичном сервере: искусственные игроки не требуют поддельных пользовательских сессий.

Вы выбираете вопрос. Соперники ждут 7 секунд, затем один нажимает кнопку и через 2 секунды пишет ответ. Верные и неверные ответы чередуются. Чтобы ответить самому, нажмите кнопку раньше соперника и напишите ответ в чат. Робоведущий через 1,5 секунды сверяет ответ с демопакетом, начисляет очки или открывает попытку для остальных; просроченные попытки закрывает автоматически. После раскрытия нажмите «Следующий вопрос». Можно завершить тренировку и создать новую.

Проверка в тренировке простая: точный текст без учёта регистра, «ё» и пунктуации; для авторов принимается фамилия, для ответов через `/` — любая записанная альтернатива. Синонимы и опечатки автоматически не распознаются. В обычной комнате ответ оценивает живой ведущий.

Чат хранит последние 100 сообщений комнаты в SQLite. Тренировка восстанавливается после перезапуска сервера; боты продолжают по сохранённому состоянию. Поле вопроса и правильный ответ до раскрытия видны только ведущему; игрок видит лишь текст вопроса.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Проверяются одновременные нажатия, права, скрытие ответов, очки, повторные попытки, таймеры, сохранение SQLite, подпись Telegram, HTTP и WebSocket.
