# Крысиные бега — Telegram Mini App

Квиз для ведущего и до 8 игроков: одновременные текстовые ответы, вопросы с изображениями, аудио и видео, случайные события. Python 3.9+, FastAPI, SQLite, HTML/CSS/JS, WebSocket. Сборка фронтенда не требуется.

## Локальный запуск

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. `DEV_MODE=true` разрешает вход под любым именем. Второго игрока откройте в другом браузере или приватном окне. После настройки окружения можно использовать `start-local.cmd`.

## Telegram и сервер

Локальная разработка → GitHub → сервер: [инструкция развёртывания](deploy/README.md). Серверные настройки и SQLite находятся отдельно от кода. Для публичного сервера установите `DEV_MODE=false`, заполните `BOT_TOKEN`, `BOT_USERNAME` и `APP_URL` (HTTPS). Бот запускается командой `python -m app.bot`; веб-приложение — Uvicorn. Одновременно работает только один экземпляр бота с одним токеном.

Временный тест внутри Telegram: поместите `cloudflared.exe` в `tools/`, заполните `BOT_TOKEN` в `.env` и запустите `start-telegram.cmd`. Скрипт запускает сервер на порту 8001, HTTPS-туннель и бота, обновляет адрес кнопки. Остановка: Ctrl+C. Этот режим использует `data/telegram.sqlite3`; локальный браузерный режим — отдельную базу. При работающем серверном боте используйте локальный браузерный режим.

Приглашения: `https://t.me/<bot>?start=<код>`. Бот выдаёт кнопку открытия комнаты. Токен не передаётся клиенту; сервер проверяет подпись и возраст Telegram `initData` и выдаёт суточную сессию.

## Правила

В Telegram на главном экране два режима: «Игрок» и «Ведущий». Игрок вводит ID комнаты и ждёт запуска ведущим; выбор игры доступен на вкладке ведущего. На экране игрока нет списка участников, таблицы счёта и чужих ответов; ID комнаты находится внизу. Вместо чата — короткие реакции, видимые всей комнате, включая общий экран.

Общий экран открывается в обычном браузере по адресу `<APP_URL>/display` (локально — `http://127.0.0.1:8000/display`). Введите код комнаты или используйте прямую ссылку из блока ведущего «Общий экран в браузере». Telegram и второй аккаунт не нужны, в том числе при `DEV_MODE=false`. Перед стартом показаны название игры, код для подключения, число раундов и вопросов; для сетки доступно превью поля первого раунда без текста вопросов и ответов. Во время игры поле и вопрос занимают всю ширину без списка участников. Общий счёт появляется по команде ведущего, итоговые места — при завершении. Экран не занимает место игрока и не управляет игрой. Сессия просмотра привязана к одной комнате, живёт до суток и восстанавливается при перезагрузке страницы. Она хранится отдельно от входа ведущего; кнопка «На весь экран» включает полноэкранный режим браузера.

Реакции ограничены одной в секунду на участника; лишние нажатия молча игнорируются и не пересобирают игровой экран. Ведущий может поставить игру на общую паузу и продолжить с сохранённым остатком времени. После последнего вопроса раунда автопереход останавливается: ведущий может показать всем общий счёт, сделать перерыв и запустить следующий раунд.

Перед каждым раундом сетки темы проходят вступительными титрами с перспективой; ведущий может пропустить вступление. Сетка показывается на общем экране и у ведущего. Игрок, которому принадлежит выбор, называет тему и стоимость, ведущий открывает ячейку. На телефонах игроков — вопрос и отправка ответа, во время выбора — ожидание. В тренировке за игрока доступен выбор ячейки на телефоне. В финале всем по серверному времени открываются последние места, затем третье, второе и первое, с фанфарами и конфетти. При равном счёте участники делят место. Звук включается после взаимодействия с приложением либо кнопкой «Включить фанфары»; настройка уменьшения анимаций учитывается.

В панели «Управление игроками · очки и эффекты» ведущий выбирает игрока и добавляет или снимает произвольное количество очков, выдаёт ловушку или бонус на выбранное число вопросов, снимает эффект. Управление доступно и на паузе. Во время открытого вопроса изменение эффекта действует сразу; после закрытия — со следующего вопроса, сохраняя правила оценки уже закрытого. Игрок видит иконку, описание и оставшуюся длительность своего эффекта.

Кнопка «Пропустить раунд» переводит к следующему игровому раунду, а в последнем — к итогам. Уже начисленные очки сохраняются, неоценённые ответы и оставшиеся вопросы пропускаются без начислений. Пауза сохраняется при переходе к следующему раунду.

Аудио и видео автоматически запускаются на демонстрации при открытии вопроса. Если браузер требует разрешения на звук, на этом экране нужно один раз нажать «Включить звук». Плеер показывает время относительно выбранного отрывка и позволяет перематывать ползунком в его границах; одна кнопка переключает воспроизведение и паузу, кнопок ±5 секунд нет. У ведущего вместо местного плеера — одна кнопка «Воспроизвести / Пауза» для записи на демонстрации. Её подпись следует состоянию записи, включая управление с общего экрана. Позиция и пауза сохраняются в комнате и передаются через WebSocket; общая пауза останавливает и запись. На экране игрока аудио и видео не загружаются и не показываются, изображения остаются доступны.

После проверки последнего ответа раунда промежуточный счёт появляется автоматически. Если последний вопрос содержит аудио/видео, сначала проигрывается полная запись: по её окончании демонстрация переходит к счёту. Ведущий может открыть счёт раньше кнопкой «Показать счёт раунда». Автопереход работает только между вопросами текущего раунда. Между раундами игра ждёт на экране результатов; следующий раунд (или награждение после последнего) запускает ведущий. Это правило действует и в тренировке.

У ведущего один рабочий экран без бокового списка участников. В лобби видно количество подключившихся игроков. Компактный пульт переключает вопрос, ответ, сетку и паузу; сетка и текущий вопрос показываются по отдельности. При проверке остаются только ответы, ожидающие оценки, и счётчик проверенных ответов. Подключение общего экрана, корректировка очков и эффектов, добавление вопросов, пропуск раунда и завершение игры собраны в сворачиваемом меню «Ещё». Кнопка «Вернуться к сетке» сохраняет завершённый вопрос, чтобы ведущий мог снова показать ответ.

Проверка сценариев интерфейса без браузера: `node --test tests/ui_game.test.cjs` (Node.js 18+).

Панель ведущего «Демонстрационный экран» переключает вопрос, ответ, сетку и список участников со счётом независимо от экранов игроков. Ответ доступен только после проверки всех полученных ответов; до этого игроки видят только свой ответ. После последней оценки общий экран автоматически показывает крупный правильный ответ и запускает аудио/видео с начала целиком, без границ отрывка. Автопереход через 3 секунды для такого вопроса отключается: ведущий сам решает, когда продолжить. Возврат к сетке приостанавливает запись; вернувшись к ответу, ведущий может продолжить её кнопкой воспроизведения. Индивидуальные ответы и отметки «верно/неверно» на общий экран не передаются. «Пауза игры» останавливает таймер и запись и показывает экран перерыва. Отдельная кнопка «Показать счёт» также ставит игру на паузу, но выводит на демонстрацию список игроков с общими баллами вместо вопроса. Игроки в обоих случаях видят сообщение о перерыве. Между перерывом и счётом можно переключаться, не возобновляя игру и не меняя сохранённое время. «Продолжить игру» возвращает демонстрацию к прежнему экрану, возобновляет таймер и запись с сохранённой позиции. Проверенные ответы и баллы сохраняются.

Чтобы провести игру одному со стороны ведущего, откройте «Ведущий», выберите игру и нажмите «Попробовать как ведущий». Откроется лобби с тремя ботами: запускайте игру, проверяйте их текстовые ответы вручную, ставьте паузу, показывайте счёт и переходите между раундами. Два варианта ответа оцениваются автоматически по обычным правилам. Если в сетке ход получил бот, ведущий выбирает за него. «Сыграть за игрока» запускает прежнюю тренировку с Робоведущим.

Свои игры создавайте и публикуйте в веб-конструкторе, затем выбирайте их в Mini App для проведения или репетиции.

Ведущий запускает раунды и оценивает текстовые ответы отдельно; вопросы с двумя вариантами проверяются автоматически. По умолчанию все игроки отвечают одновременно, по одному ответу на вопрос. Ведущий видит ответы сразу. Демонстрация показывает правильный ответ после проверки. Приём закрывается по таймеру, когда ответили все допущенные игроки, или по кнопке ведущего.

Одна игра может содержать до 30 игровых раундов в любом порядке, включая повторения режимов. Счёт общий на всю комнату:

- **Блиц:** вопросы по порядку или случайно. Переход после проверки — по кнопке ведущего или автоматически через 3 секунды.
- **Сетка вопросов:** выбор категории и стоимости. Первый вопрос выбирает ведущий. Далее выбирает ведущий либо первый по времени правильно ответивший игрок, согласно настройке раунда. Если верных ответов нет, выбирает ведущий; он также может выбрать вопрос сам. В конструкторе настройка «Кто отвечает на вопрос?» (`answer_mode`) задаёт `all` — отвечают все, или `single` — отвечает один. В режиме одного ответа первый нажавший «Ответить» получает право ввода, остальные ждут. После отправки этого ответа начинается проверка, повторного перехвата после ошибки нет. Пропустившие ответ очков не теряют. Старые сетки без этой настройки сохраняют одновременные ответы.
- **Выбор из двух:** две кнопки с любыми подписями, например «Да / Нет». После закрытия вопроса варианты автоматически оцениваются. Пропуск даёт 0 очков.

Редактор разделяет раунды игры и вопросы внутри каждого раунда. Пример смешанной игры: [games/mixed-rounds/game.json](games/mixed-rounds/game.json). Старые пакеты без настроек раундов работают как один последовательный блиц с ручным переходом.

Верно: +стоимость, неверно: −стоимость, пропуск: 0. События могут изменить награду или штраф. Следующий раунд доступен после оценки всех полученных ответов. Новые игроки входят до старта; участники могут переподключаться. Комната сохраняет копию игры и медиа: обновление исходного пакета не меняет начатую игру.

## Игры из файла

Игры также можно создавать через отдельный [веб-конструктор](#веб-конструктор-игр): он сохраняет тот же формат `game.json`.

Единственный формат — **game.json**, UTF-8. Готовый пример: [games/example-race/game.json](games/example-race/game.json). Описание полей и событий: [games/README.md](games/README.md).

Локально положите папку игры в `data/games/<имя>/`, на сервере — в `/var/lib/rat-race/games/<имя>/`. Внутри: `game.json` и файлы медиа, на которые он ссылается. Имя папки: латинские буквы, цифры, `_`, `-`. Загрузите всю папку через SFTP и нажмите «Обновить список игр» на главном экране. Перезапуск приложения не требуется. Пакеты из каталога репозитория `games/` также доступны; серверный пакет с тем же именем имеет приоритет.

```powershell
.\.venv\Scripts\python.exe scripts/validate_pack.py games/example-race
```

В лобби ведущий может добавлять вопросы и материалы через интерфейс. Изображения: PNG/JPEG/GIF/WebP; аудио: MP3/WAV/OGG/M4A; видео: MP4/WebM. Файл — до 25 МБ, медиа пакета — до 100 МБ. Кодек должен поддерживаться браузером Telegram. Границы аудио/видео задают воспроизводимый отрывок; файл хранится целиком.

## Веб-конструктор игр

Конструктор — отдельный сервис для авторов. Проведение игр остаётся в Telegram Mini App.

Для локального запуска откройте `start-builder.cmd` или выполните:

```powershell
.\.venv\Scripts\python.exe scripts/run_builder.py
```

Адрес: http://127.0.0.1:8124. При первом запуске пароль генерируется в `data/builder-access.txt`, его хеш хранится в `data/builder.env`. Эти файлы исключены из Git.

В конструкторе доступны библиотека игр, создание и редактирование вопросов и событий, порядок раундов, изображения, аудио и видео с отрывками, предпросмотр, импорт `game.json` и скачивание ZIP с медиа. «Сохранить черновик» хранит изменения отдельно в `data/builder/drafts/`. «Опубликовать» проверяет пакет и обновляет `data/games/`; игра появляется в Mini App после обновления списка. Комнаты используют свою копию игры. Предыдущий документ сохраняется в `data/builder/backups/`.

Библиотека редактора содержит все готовые игры Mini App, включая встроенный «Демоквиз», пример с медиа и событиями и пример трёх режимов. Новые игры создаются кнопкой «Новая игра» в веб-редакторе. Редактирование «Демоквиза» публикует внешнюю версию `demo-quiz`, которая используется и обычной комнатой, и тренировкой.

Редактор разделён на «Раунды», «Об игре» и «Файлы и публикация». Внутри выбранного раунда отдельно открываются вопросы и настройки режима. На узком экране библиотека открывается кнопкой «Мои игры».

Перед публикацией и скачиванием ZIP редактор показывает список незаполненных или неверных полей с номером игрового раунда и вопроса либо события внутри него. Нажатие на замечание открывает нужную карточку и подсвеченное поле. После исправления список обновляется автоматически; проверка не меняет сохранённый черновик или опубликованную версию.

Категории доступны только в раундах с сеткой, на вкладке «Категории». Сводка и счётчики относятся к выбранной сетке; нажатие на счётчик открывает вопросы категории. Список вопросов можно фильтровать по категории и искать по тексту. Новый вопрос при активном фильтре сразу получает выбранную категорию. Публикация вопросов сетки без категории запрещена. Переименование категории обновляет её вопросы, удаление снимает их привязку. Медиа, допустимые ответы для тренировки и предпросмотр находятся в раскрывающихся блоках карточки вопроса.

Изменения из другого окна и внешние обновления игры проверяются перед записью. Кнопка «Загрузить опубликованную версию» заменяет черновик и сохраняет его резервную копию. Импорт переносит вопросы; отсутствующие медиа нужно загрузить отдельно. Ограничения файлов совпадают с Mini App.

«Скачать ZIP с медиа» на вкладке «Файлы и публикация» сохраняет `game.json` и все используемые изображения, аудио и видео с исходными путями. Удаление доступно через корзину в библиотеке и во вкладке «Об игре», с подтверждением. Оно убирает черновик, опубликованный пакет и все их медиа из активных папок. Начатые комнаты сохраняют вопросы и свою копию медиа. Перед удалением полная резервная копия сохраняется в закрытом `data/builder/backups/<id>/*-deleted.zip`. Маркеры в `data/games/.deleted/` скрывают удалённые встроенные примеры и после обновлений из GitHub; исходные файлы примеров в Git не изменяются.

В карточке события выбираются положительный или отрицательный эффект, конкретное действие, его величина, получатели и длительность. Помимо случайных эффектов доступны двойная награда, защита, половина награды, двойной штраф, произвольные множители и дополнительные очки за верный ответ или ошибку. Получателями могут быть все, случайный игрок, лидер или последний игрок. Новое событие заменяет прежний эффект у своих получателей.

Для аудио и видео редактор показывает плеер и ползунки начала и конца отрывка. Время можно ввести в секундах или как `01:23.5`, взять границу по позиции плеера, выбрать 10/30 секунд либо всю запись и прослушать отрывок. Границы учитывают длительность файла; старый предел 86400 секунд снят. Таймер ответа задаётся отдельно: от 1 секунды без прежнего максимума 300. Очки задаются от 0 без прежнего максимума 1000. Максимум 5 вопросов для длительности эффектов также снят.

Отдельный серверный запуск и обновление через GitHub описаны в [инструкции развёртывания](deploy/README.md#конструктор-игр).

## Тренировка

Выберите готовую игру и нажмите «Играть с искусственными игроками». Ваша учётка становится игроком, Робоведущий проверяет ответы, Сырник и Шустрик отвечают через 5 и 8 секунд. Верные и неверные ответы чередуются. После закрытия приёма Робоведущий оценивает ответы через 1,5 секунды. После вопроса или события переходите дальше кнопкой.

Автопроверка принимает точный ответ и `accepted_answers` без учёта регистра, «ё» и пунктуации. Опечатки автоматически не исправляются. В обычной комнате решение принимает живой ведущий. На публичном сервере вход через Telegram обязателен.

## Хранение и проверка

SQLite: `DATABASE_PATH`, по умолчанию `data/game.sqlite3`. Материалы комнат находятся рядом с базой в `media/`. Для полной резервной копии сохраняйте SQLite, `media/` и авторские `games/`. Комнаты, очки, эффекты, сессии и последние 100 сообщений сохраняются после перезапуска. Автоматической очистки комнат и материалов пока нет.

Запускайте один процесс Uvicorn без `--workers`: WebSocket-подключения хранятся в памяти.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Проверяются параллельные ответы, приватность, оценки и штрафы, таймеры, эффекты и их длительность, искусственные игроки, JSON, медиа и права доступа, Telegram-подпись, HTTP и WebSocket.
