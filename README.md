# Крысиные бега

Выпуск версий и обновление сервера: [RELEASING.md](RELEASING.md). Изменения релизов: [CHANGELOG.md](CHANGELOG.md).

Игра-викторина в Telegram и веб-браузере для ведущего и до 8 игроков. Поддерживает текстовые вопросы, изображения, аудио, видео и игровые бонусы.

Версия из `VERSION` отображается в приложении, редакторе и на общем экране: `<версия> build <короткий хеш коммита>`.

## Как играть

1. Ведущий открывает приложение через Telegram-бота или в браузере, выбирает игру и создаёт комнату.
2. Игроки подключаются по коду комнаты или приглашению. В браузере достаточно ввести имя; в Telegram имя подставляется автоматически. Участники обоих способов входа играют вместе.
3. Ведущий запускает раунды и проверяет ответы. Таймера вопроса нет. В «Выборе из двух» приём ответов закрывает ведущий, затем варианты проверяются автоматически.
4. Последний ответ остаётся на экране, пока ведущий не нажмёт «Завершить раунд». Затем он отдельно выбирает счёт, следующий раунд или итоговые места.

В браузере сессия сохраняется на 24 часа: при обновлении страницы или повторном открытии ссылки игрок вернётся под своим именем. Имя не является паролем: одинаковые имена в разных браузерах создают разных участников. Ведущий может скопировать веб-ссылку или приглашение через Telegram. Кнопка «Выйти» на главной странице завершает веб-сессию и позволяет войти под другим именем.

Ведущий переключает «Показать вопрос» и «Показать ответ». Показ ответа закрывает приём ответов и запускает прикреплённые к ответу аудио и видео на демонстрации. Медиа вопроса на экране ответа не показывается. Текстовые ответы также появляются только по команде ведущего. После возврата к вопросу приём ответов остаётся закрытым. На демонстрации элементы плеера скрыты; воспроизведением и громкостью управляет ведущий.

Есть три режима: **блиц**, **сетка с выбором темы и стоимости**, **выбор из двух ответов**. В сетке могут отвечать все игроки или один — тот, кто первым нажал кнопку ответа.

Если в сетке следующий вопрос выбирает победитель, его панель выбора открывается после команды ведущего «Показать сетку». До команды «Показать ответ» игрокам не передаются правильный вариант и вложения ответа. При повторном показе ответа его запись начинается заново; запоздавшие команды предыдущего плеера игнорируются.

Для телевизора или проектора откройте `<адрес приложения>/display` и введите код комнаты. Звук и видео воспроизводятся на этом экране. Ведущий может поставить игру на паузу и показать результаты.

Для знакомства с приложением доступны тренировки за игрока и за ведущего с ботами. В тренировке за игрока медиа воспроизводятся на его устройстве и запускаются кнопкой воспроизведения.

## Создание игр

В веб-конструкторе создайте игру, добавьте раунды и вопросы, загрузите материалы и нажмите «Опубликовать». Затем обновите список игр в приложении.

В «Настройках игры» задаются очки и предзагрузка медиа на демонстрационный экран (по умолчанию включена). Подключите экран перед запуском игры и дождитесь сообщения «Медиа готовы»: все файлы вопроса и ответа загружаются целиком и используются локально до закрытия или обновления страницы. Для команд ведущего нужна связь с сервером. Если браузер запросит разрешение на звук, разрешите его на демонстрационном экране. Старые настройки времени сохраняются в документах для совместимости, но не ограничивают ответы игроков. Удаление раунда или категории удаляет и их вопросы после подтверждения.

Можно сохранить черновик или скачать игру вместе с материалами в ZIP. Для ручного редактирования есть [краткое описание game.json](games/README.md).

## Запуск на компьютере

Нужен Python 3.9+. В PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\commands\start-local.cmd
```

Откройте http://127.0.0.1:8000. Локально можно войти под любым именем. Для второго игрока используйте другой браузер или приватное окно.

Конструктор запускается через `commands\start-builder.cmd`: http://127.0.0.1:8124. Пароль при первом запуске сохраняется в `data/builder-access.txt`. Все CMD-файлы собраны в папке [commands](commands/README.md).

## Сервер

Установка и обновление выполняются через GitHub, ветку `main`. На сервере доступны команды `rat-race`, с Windows — `commands\server.cmd`. Доступы хранятся в приватном `server.txt`.

[Установка и управление сервером →](deploy/README.md)

## Проверка изменений

```powershell
.\.venv\Scripts\python.exe -m pytest -q
node --test tests/ui_game.test.cjs tests/ui_builder.test.cjs
```

Для второй команды нужен Node.js 18+.
