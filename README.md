# Крысиные бега

Игра-викторина в Telegram для ведущего и до 8 игроков. Поддерживает текстовые вопросы, изображения, аудио, видео и игровые бонусы.

Версия отображается в приложении, редакторе и на общем экране: `0.0.5 build <короткий хеш коммита>`.

## Как играть

1. Ведущий открывает приложение, выбирает игру и создаёт комнату.
2. Игроки подключаются по коду комнаты или приглашению.
3. Ведущий запускает раунды и проверяет ответы. Вопросы с двумя вариантами проверяются автоматически.
4. Последний ответ остаётся на экране, пока ведущий не нажмёт «Завершить раунд». Затем он отдельно выбирает счёт, следующий раунд или итоговые места.

Аудио и видео запускаются кнопкой ведущего; после открытия вопроса и правильного ответа запись ждёт команды. На демонстрации элементы плеера скрыты. Компактная шапка оставляет место для медиа, а кнопка полноэкранного режима отдаёт область страницы вопросу.

Есть три режима: **блиц**, **сетка с выбором темы и стоимости**, **выбор из двух ответов**. В сетке могут отвечать все игроки или один — тот, кто первым нажал кнопку ответа.

Для телевизора или проектора откройте `<адрес приложения>/display` и введите код комнаты. Звук и видео воспроизводятся на этом экране. Ведущий может поставить игру на паузу и показать результаты.

Для знакомства с приложением доступны тренировки за игрока и за ведущего с ботами.

## Создание игр

В веб-конструкторе создайте игру, добавьте раунды и вопросы, загрузите материалы и нажмите «Опубликовать». Затем обновите список игр в приложении.

В «Настройках игры» задаются общее время ответа и очки; отдельный вопрос может иметь свои значения. Удаление раунда или категории удаляет и их вопросы после подтверждения.

Можно сохранить черновик или скачать игру вместе с материалами в ZIP. Для ручного редактирования есть [краткое описание game.json](games/README.md).

## Запуск на компьютере

Нужен Python 3.9+. В PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\commands\start-local.cmd
```

Откройте http://127.0.0.1:8000. Локально можно войти под любым именем. Для второго игрока используйте другой браузер или приватное окно.

Конструктор запускается через `commands\start-builder.cmd`: http://127.0.0.1:8124. Пароль при первом запуске сохраняется в `data/builder-access.txt`. Все CMD-файлы собраны в папке [commands](commands/README.md).

## Сервер

Установка и обновление выполняются через GitHub, ветку `main`. На сервере доступны команды `rat-race`, с Windows — `commands\server.cmd`. Доступы хранятся в приватном `data/builder-server-access.txt`.

## Проверка изменений

```powershell
.\.venv\Scripts\python.exe -m pytest -q
node --test tests/ui_game.test.cjs tests/ui_builder.test.cjs
```

Для второй команды нужен Node.js 18+.
