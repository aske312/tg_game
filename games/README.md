# Игры и game.json

Проще всего создавать игры в веб-конструкторе: добавить раунды, вопросы и материалы, затем нажать «Опубликовать».

Для ручного редактирования игра хранится в папке с файлом `game.json`. Изображения, аудио и видео находятся рядом, обычно в подпапке `media/`.

## Простой пример

```json
{
  "schema_version": 1,
  "title": "Моя игра",
  "rounds": [
    {
      "id": "q1",
      "type": "question",
      "text": "Сколько будет 2 + 2?",
      "answer": "4",
      "points": 100,
      "time_limit": 45
    }
  ]
}
```

`points` — стоимость вопроса. Старое поле `time_limit` принимается для совместимости; вопрос работает без таймера. Для тренировки можно добавить варианты правильного ответа в `accepted_answers`.

Общие настройки задаются в корне игры: `"settings": {"points": 100, "preload_media": true}`. Вопрос без своей стоимости использует очки из настройки игры (по умолчанию 100). `preload_media` включает загрузку всех файлов на демонстрационный экран до игры; по умолчанию включён. Дождитесь готовности файлов на подключённом экране. Переходы, показ ответа и завершение вопроса выполняет ведущий; `auto_advance` в старых документах больше не включает автоматический переход в игре с ведущим.

## Раунды и материалы

| Режим | Значение `type` | Особенности |
| --- | --- | --- |
| Блиц | `blitz` | Вопросы идут по порядку или случайно |
| Сетка | `grid` | Нужны категории и стоимость вопросов |
| Выбор из двух | `binary` | В вопросе указываются `choices` и `correct_choice` — 0 или 1 |

Список игровых раундов задаётся в `stages`, а вопросы в `rounds` связываются с ними через поле `stage`. Без `stages` игра работает как один блиц.

Материалы добавляются к вопросу полем `media`: тип (`image`, `audio`, `video`) и относительный путь `file`. Для аудио и видео можно задать отрывок через `start` и `end` в секундах. `audio_only: true` у видео оставляет только звук в вопросе. Чтобы показать видео в ответе, добавьте его отдельно с `answer: true`. Один файл и все материалы игры — до 10 ГБ (10 × 1024³ байт). Повторные ссылки на один файл не увеличивают размер пакета. В квоту черновика входят также ранее загруженные файлы.

В редакторе переключатель «Показывать медиаматериал во время вопроса» сохраняется как `media.show_in_question` (по умолчанию `true`). Значение `false` скрывает изображение на демонстрации до сцены с правильным ответом; звук аудио и видео остаётся. Старая настройка видео `audio_only: true` поддерживается и отображается как выключенный показ. У аудио на демонстрации нет плеера или подписи дорожки.

Изображения: PNG, JPEG/JFIF, GIF, WebP, AVIF, BMP. Аудио: MP3, WAV, OGG/OGA/Opus, M4A, AAC, FLAC. Видео: MP4, WebM, MOV, M4V. При загрузке формат определяется по содержимому файла; JFIF сохраняется как JPEG без перекодирования. Видео и аудио должны использовать кодеки, которые воспроизводятся в браузере участников.

Несколько файлов можно добавить в `attachments` — список объектов с такими же полями, как у `media`. У файла ответа укажи `"answer": true`: он показывается только в сцене ответа. Предзагрузка скачивает файл заранее, не раскрывая его на экране. Например: `"attachments": [{"type": "image", "file": "media/second.png"}, {"type": "video", "file": "media/answer.mp4", "answer": true}]`. Допускается до 20 дополнительных файлов; общий лимит игры — 10 ГБ. Аудио и видео ответа запускаются по команде «Показать ответ»; управление воспроизведением находится у ведущего. Файлы вопроса не переносятся в сцену ответа автоматически.

Бонусы и ловушки добавляются как элементы с `type: "event"`. Их удобнее настраивать в конструкторе.

## Добавление в приложение

Опубликуйте игру через конструктор или поместите её папку в `data/games/` локально, на сервере — в `/var/lib/rat-race/games/`. Затем нажмите «Обновить список игр» в приложении. Уже начатые комнаты сохраняют свою версию игры.

Проверка файла перед загрузкой:

```powershell
.\.venv\Scripts\python.exe scripts/validate_pack.py games/example-race
```
