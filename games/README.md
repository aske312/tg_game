# Формат игры: game.json

Одна игра — папка с единственным документом `game.json` и необязательными медиа. Все правила и раунды описаны в JSON; YAML не используется. Рабочий пример: [example-race/game.json](example-race/game.json).

```json
{
  "schema_version": 1,
  "title": "Крысиные бега",
  "rounds": [
    {
      "id": "q1",
      "type": "question",
      "text": "Сколько будет 2 + 2?",
      "answer": "4",
      "accepted_answers": ["четыре"],
      "points": 100,
      "time_limit": 45
    },
    {
      "id": "e1",
      "type": "event",
      "title": "Сырный бонус",
      "text": "Случайный игрок получает усиление!",
      "effect": {
        "type": "random_buff",
        "target": "random_player",
        "questions": 2
      }
    }
  ]
}
```

Раунды идут в порядке `rounds`. Нужен хотя бы один вопрос; максимум 100 раундов. `title` — до 100 символов, необязательное `description` — до 500. Документ — до 1 МБ. `id` уникален, содержит латинские буквы, цифры, `_`, `-`, до 64 символов; без него используется `q` с номером раунда.

## Вопрос

`type: "question"`, обязательные `text` (до 2000 символов) и `answer` (до 500). `points`: 10–1000, по умолчанию 100. `time_limit`: 10–300 секунд, по умолчанию 45. Необязательные `category` и `accepted_answers` (до 20 вариантов) используются для подписи и автопроверки тренировки. Живой ведущий проверяет ответы сам.

Для медиа добавьте к вопросу:

```json
"media": {
  "type": "video",
  "file": "media/clip.mp4",
  "start": 5,
  "end": 15
}
```

`type`: `image`, `audio`, `video`. `file` — относительный путь внутри папки игры. Для аудио и видео `start`/`end` задаются в секундах; по умолчанию весь файл. Изображения: PNG/JPEG/GIF/WebP; аудио: MP3/WAV/OGG/M4A; видео: MP4/WebM. Файл до 25 МБ, суммарно до 100 МБ. Формат проверяется по содержимому. Используйте поддерживаемые браузером кодеки, например H.264 для MP4. Файлы остаются отдельными вложениями; JSON содержит ссылки на них.

## Событие

`type: "event"`, `title`, необязательный `text`, обязательный `effect`:

| Поле | Значения |
|---|---|
| `type` | `random_buff` или `random_debuff` |
| `target` | `random_player` или `all_players` |
| `questions` | 1–5 следующих вопросов, по умолчанию 1 |

Баф случайно выбирает двойную награду за верный ответ или защиту от штрафа. Дебаф — половину награды или двойной штраф. Каждая из двух возможностей равновероятна. При `all_players` один выбранный эффект применяется ко всем. Ведущий не участвует в выборе получателя.

Событие разыгрывается один раз при открытии раунда. Результат показывается всем и сохраняется в SQLite; переподключение и перезапуск его не меняют. После события ведущий или владелец тренировки нажимает «Продолжить».

У игрока действует один эффект: новое событие заменяет прежний. Срок уменьшается после каждого закрытого вопроса, включая пропущенный. Пропуск всегда даёт 0. Половина награды округляется вниз до целых очков. После истечения срока возвращаются обычные награда и штраф.

## Загрузка

На сервере: `/var/lib/rat-race/games/my-game/game.json` и, например, `/var/lib/rat-race/games/my-game/media/clip.mp4`. Файлы должны читаться пользователем службы `ratrace`. Локально аналогично: `data/games/my-game/` (рядом с выбранной SQLite).

Сначала загрузите медиа, затем готовый `game.json`; при обновлении заменяйте документ атомарно после окончания передачи. Нажмите «Обновить список игр». Невалидная игра не попадёт в выбор; интерфейс покажет причину. Изменения используются в новых комнатах, действующие сохраняют собственную копию.
