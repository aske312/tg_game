# Установка и управление сервером

Сервер получает приложение из [GitHub](https://github.com/aske312/tg_game), ветки `main`.

## Установка

Нужны **Ubuntu 24.04+ или Debian 12+**, доступ root либо sudo, публичный домен или IP. Откройте TCP-порты **80**, **443** и **8443** для конструктора. Домен должен указывать на сервер.

Подключитесь по SSH и выполните:

```bash
sudo apt-get update
sudo apt-get install -y curl ca-certificates
curl -fsSL https://raw.githubusercontent.com/aske312/tg_game/main/deploy/install.sh -o /tmp/rat-race-install.sh
sudo bash /tmp/rat-race-install.sh
```

Установщик спросит адрес приложения, токен и имя Telegram-бота, email для HTTPS. Он настроит приложение, бота, конструктор и автоматический запуск после перезагрузки сервера.

- Только приложение и бот: добавьте `--app-only` к последней команде.
- Установка без вопросов: заполните приватный файл по [примеру](install.env.example), задайте ему права `600` и передайте `--config /root/rat-race-install.env`.
- Адрес и пароль нового конструктора: `sudo cat /etc/rat-race/builder-access.txt`.

Повторная установка сохраняет настройки, пароли и игры. На существующем сервере один раз запустите этот установщик, чтобы добавить новые команды управления. Установка и обновление перезапускают приложение — выполняйте их между играми. Если сервер уже обслуживает другие сайты, прокси нужно настроить отдельно.

## Обновление

Сначала сохраните изменения коммитом и отправьте их в GitHub:

```powershell
git push origin main
```

Затем на сервере:

```bash
sudo rat-race update
```

Обновление проверяет новую версию, сохраняет копию базы и перезапускает службы. При ошибке запуска возвращает предыдущую версию. Отправка кода в GitHub сама по себе сервер не обновляет.

## Основные команды

| Команда | Действие |
| --- | --- |
| `sudo rat-race start` | Запустить |
| `sudo rat-race stop` | Остановить |
| `sudo rat-race restart` | Перезапустить |
| `sudo rat-race update` | Обновить из GitHub |
| `sudo rat-race status` | Посмотреть состояние служб |
| `sudo rat-race logs` | Посмотреть последние записи журнала |
| `sudo rat-race health` | Проверить доступность приложения |
| `sudo rat-race version` | Показать установленную версию |

По умолчанию команда действует на все установленные части. Для одной части добавьте `app` (приложение и бот) или `builder` (конструктор). Например: `sudo rat-race update builder`. Для просмотра журнала в реальном времени: `sudo rat-race logs app --follow`.

## Управление с Windows

Один раз установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-admin.txt
```

Доступы находятся в приватном `data/builder-server-access.txt`. Для SSH в нём нужны поля ниже; адрес и пароль веб-редактора оставьте в том же файле:

```text
IP: адрес сервера
PORT: 22
USER: имя пользователя
PSW: пароль
```

Нужен root либо пользователь с sudo без запроса пароля. После установки сервера используйте те же команды:

```powershell
.\commands\server.cmd update
.\commands\server.cmd restart app
.\commands\server.cmd status
.\commands\server.cmd logs app --follow
```

## Настройки и данные

- `/etc/rat-race/` — настройки и доступы.
- `/var/lib/rat-race/` — база, игры, материалы и резервные копии.

Резервируйте оба каталога. Пароли, токены и файлы доступов не размещайте в GitHub.
